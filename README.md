# وصلني | WASALNI — Flutter Prototype

نسخة أولية تفاعلية لتجربة تدفق الرحلة محليًا على جهاز واحد.

## التشغيل
1. ثبّت Flutter SDK وAndroid Studio على الكمبيوتر.
2. فك ضغط المشروع.
3. من داخل مجلد `wasalni_flutter` نفّذ:
   - `flutter pub get`
   - `flutter run`

## الموجود في هذه النسخة
- شاشة اختيار العميل أو السائق أو الإدارة.
- العميل ينشئ طلبًا ويحدد الانطلاق والوجهة.
- السائق يقبل الطلب ويحدّث مراحل الرحلة حتى إنهائها.
- شاشة الإدارة تعرض حالة الرحلة الحالية.
- العميل يستطيع إضافة تقييم تجريبي بعد اكتمال الرحلة.

## الحدود الحالية
- حالة الرحلة مشتركة داخل ذاكرة التطبيق على الجهاز نفسه فقط.
- لا يوجد خادم أو تسجيل دخول أو قاعدة بيانات أو خرائط حقيقية أو دفع أو إشعارات.
- السعر والمسافة والوقت ليست محسوبة فعليًا.
- هذه ليست نسخة إنتاجية ولا ينبغي استخدامها لرحلات حقيقية.

## الخطوات التالية
ربط Firebase أو خادم موثوق، المصادقة والصلاحيات، خرائط وموقع GPS، احتساب الأجرة، الإشعارات، اختبارات الأمان، ثم إنشاء Android App Bundle (AAB) والنشر بعد استيفاء متطلبات Google Play.
